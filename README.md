# XMC Reddening Map

XMC Reddening Map of the Magellanic Clouds

This repository provides the high-resolution reddening map of the Magellanic Clouds used in:

Oden, S. J., et al. 2025, "Warped & Hooked: Mapping the Magellanic Clouds in 3D using Red Clump Stars", arXiv:2512.04200, doi:10.48550/arXiv.2512.04200

The reddening map combines OGLE-IV reddening measurements (Skowron et al. 2021) with recalibrated Schlegel et al. (1998) dust maps.

## Data Product

oden_ebv_3arcmin.fits

### Description:
  - Angular resolution: 3 arcminutes
  - Quantity: E(B−V) reddening
  - Coordinate system: Galactic

This file represents the final peer-reviewed reddening product used in the associated manuscript.
